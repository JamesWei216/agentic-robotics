# 自然语言任务书 · 变体任务 B：批量分拣（数量 ×2 + 位置重排）

> 变体考察点：**同一工位、同一份 Agent 框架**，只改物料数量与初始位置。
> 分类规则（小→蓝、大→红）、成功判定谓词、约束、人确认要求与主任务完全一致。
> 目的：验证 Agent 的**泛化能力**与**改动成本**。

## 1. 与主任务的差异（两处）

| 项 | 主任务 A（libero_bolt_v2） | 变体任务 B（libero_bolt_multi） |
|---|---|---|
| 物料数量 | 1 小螺栓 + 1 大螺栓 | **2 小螺栓 + 2 大螺栓** |
| 初始位置 | 5 套布局，各 2 个落点 | 5 套布局，各 **4 个**落点（重排） |
| 分类规则 | 小 → 蓝盒，大 → 红盒 | **完全相同** |
| 工位 / 相机 / 控制方式 | — | **完全相同** |

## 2. 工位

与主任务 A 同一套工作单元（桌面 0.90 m、Franka + 平行夹爪、`agentview` + 腕部相机、
料盒位于 y≈0.16–0.19 的可达弧带内）。**不新增工作单元，不换仿真平台。**

## 3. 物料与目标区域

| 物体 | 说明 | 目标 |
|---|---|---|
| `bolt_small_1` / `bolt_small_2` | 小螺栓（62 mm，六角对边 22 mm），亮钢色 | 蓝色料盒 |
| `bolt_large_1` / `bolt_large_2` | 大螺栓（103 mm，六角对边 38 mm），深灰发黑 | 红色料盒 |
| `parts_bin_blue_1` | 蓝色料盒 | — |
| `parts_bin_red_1` | 红色料盒 | — |

## 4. 任务目标

把场上的**全部**小螺栓放进蓝色料盒，**全部**大螺栓放进红色料盒，完成后回到安全位。

存在的任务形态：

- 单类别批量：`两枚小螺栓 → 蓝盒` / `两枚大螺栓 → 红盒`
- 全量批量：`两枚小螺栓 → 蓝盒 且 两枚大螺栓 → 红盒`（4 件，长程）

## 5. 成功判定

- 单件成功：目标螺栓质心落入目标料盒内腔（`In(bolt, bin)`）。
- 任务成功：**任务要求的所有螺栓**同时满足 `In`，且机器人回到安全位。
- 未要求分拣的螺栓视为无关物体，**不得因它们失败**（判定以任务书列举的物体为准）。

## 6. 约束

与主任务 A 第 5 章完全一致。补充：

1. 连续分拣多件时，每件之间允许回到安全位或直接前往下一目标；但**同一时刻只能夹持一件**。
2. 已完成放置的料盒不得再次进入（避免把已放入的螺栓碰出）。
3. 单 episode 步数预算随件数线性放宽（协议：`400 + 800 × 件数`）。

## 7. 人机确认要求

与主任务 A 完全一致：首次运动 / 夹爪闭合 / 夹爪张开；多件任务按件重复触发。

## 8. 已知风险点

- 多件同场 → 抓取目标附近可能有其它螺栓，**先确认抓取点上没有别的物体**。
- 料盒已装有螺栓后，后续放置的内腔有效空间变小，释放高度需更贴近内腔底面。
- 长程任务（4 件）对步数预算敏感，失败重试次数必须受控（默认每件最多重试 1 次）。
- 螺栓之间可能互相遮挡，感知缺失时应先回落 `R.todo()` 的权威清单。

## 9. 交付要求

- **代码改动量必须可量化**：主任务 → 变体的 Agent 侧 diff（行数）。
- 变体任务成功率与主任务对比表。
- 若某件失败，给出失败阶段与不影响其它件的处理方式。
